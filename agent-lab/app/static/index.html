Sandbox self-test

Starts a short Claude Code session that tries to read your home folder, list ~/Documents, write outside the lab, write inside it, and reach the internet. Then it repeats the risky checks through the GPU launcher, and checks that the GPU is visible through it. Everything outside the lab should be blocked; internet and GPU should work.

Agent Lab server

Agent Lab runs in the background: the Terminal window that starts it closes itself. Stop it here, and open the Agent Lab icon to start it again. Its output goes to agent-lab/runtime/server.log.
